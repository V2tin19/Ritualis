## 壹 · 项目宗旨与根本认知

**礼序台（Ritual Order Platform）** 旨在摒弃近代流于神煞口诀、神秘宿命论与冷硬化学元素式的刻板标签，回归三代周礼与《周易》《黄帝内经》原典所奠定的**古典物理与自然气机哲学**。

### 1. 易为物理，变为体，衡为用
* **易不是玄学，是物理**：是宇宙时空事物运行之理，是气机动静变化的学问。孔颖达《周易正义》明“变易”之旨，张载《正蒙》指造化所成皆在气机聚散。
* **五行非五种死物**：绝非化学元素周期表，而是五种**正在发生的变化趋势**：
  * **木**：生发、扩张、向上、条达、曲直（少阳之气）
  * **火**：宣散、升腾、发热、明亮、转化（太阳之气）
  * **土**：承载、转化、缓冲、稳定、中和（阴阳枢纽）
  * **金**：收敛、致密、从革、肃杀、成器（少阴之气）
  * **水**：闭藏、流动、渗透、润下、归根（太阴之气）
* **一句话心法**：
  > **不问“它是什么”，只问“它在怎么变”；  
  > 不补“缺了什么”，只通“堵在哪里”。**

### 2. 核心分析方法
* **气机取象**：不问材质成分，只问气机走向：收还是散？流还是止？润还是燥？刚还是柔？进还是退？
* **形神二气**：天干为神为气，地支为形为质。地支刑冲需形气重叠方成立，天干生合可通过神气媒介运作。
* **冲合优先于生克**：优先级为 **三合 ＞ 六合 ＞ 冲 ＞ 生克**；**紧贴 ＞ 隔位 ＞ 遥隔**。合能解冲，冲能破合。忌神喜合（合绊羁绊则不为害），喜神忌合（合绊则发力受制）。
* **紫砂壶辩论法（火生土之物理真相）**：
  * 传统误以为陶器烧成后器内“残留火气”需养壶去火。实则火是能量释放与氧化反应，热源撤离冷却即散，无根之火不残留。
  * **真相**：火生土，非火化为土，乃火的性质（高温、去水、重结晶）改变了土的性质。陶器成，火性已散，土性已新，**土得金用（遇水不溶不软）**。
* **通关思维与辨辰土之变**：
  * 《滴天髓》：“两神对峙，各不相下，须调和之为美，此以通关为用也。关内有织女，关外有牛郎，此关若通也，相邀入洞房。”
  * 通关不是补缺口，是通堵塞。
  * **辰土制水有条件**：辰为水库，水旺时随水同化，不能制水；唯有火土合力烘烤辰中癸水，辰由湿转燥后，方能制水。

## 贰 · 可交互五行气机全景盘 (Web 门面)

本项目门面设计**坚决抛弃现代化的扁平科技风与极简冷淡风**，全面回归**早期互联网时期（Web 1.0 古雅典籍风）**：
* **古纸宣卷质感**：牙黄色古籍宣纸纹理、宋明雕版双线边框、云雷回纹饰角。
* **古典金石朱印**：朱砂泥印印章、雕刻铭牌。
* **经典拟物琉璃晶球**：顶端**金**（纯暖金琉璃）、右侧**水**（天青晶露）、右下**木**（翡翠碧珠）、左下**火**（丹朱烈焰）、左侧**土**（玄褐紫陶），原汁原味还原早期互联网立体球体高光与折射质感。
* **外周相生环与内圈五角星相克**：
  * 外周环流顺时针相生绿色圆弧，标有带圆圈的【生】字徽标。
  * 内圈红、黄、绿、灰、蓝五色彩线折射互克，标有圆圈【克】字徽标。
  * 内部射线交汇处嵌有彩色通关小珠（原图特征）。

### 盘面全要素交互功能：
1. **点击任意主星（金/水/木/火/土）**：
   * 盘面联动高亮其所有生入、生出、克入、克出链条。
   * 右侧【气机象解】展示其本元气机走向、体用定性、现代物理学映射。
2. **点击外环【生】字徽标或弧线（如 木生火、火生土、土生金、金生水、水生木）**：
   * 揭示相生长养机制、能量跃迁与【贪生忘克】动力学：
     * **贪生忘克**：水欲克火，遇木畅通则“水贪生木，木再生火”，克性化为长养。
     * **成立前提**：**生路必须通达畅顺！** 若生路被堵（如近克截胡、合绊阻滞、无处泄秀），贪生无力，掉头直克！
     * **母慈灭子**（土多金埋、水多木漂、木多火窒、火多土焦、金多水浊）与**子旺母衰**。
3. **点击内圈【克】字徽标或折线（如 火克金、金克木、木克土、土克水、水克火）**：
   * 揭示相克之制化维衡（“亢则害，承乃制”）。
   * 展开【两神对峙通关解法】（如何化干戈为玉帛）。
   * 展开【贪合忘克 / 贪合忘冲之羁绊】与【反克乘侮】（木坚金缺、金多火熄、火炎水涸、水多土流、土重木折）。
4. **点击内部交叉彩珠（枢纽通关节点）**：
   * 展开通关枢纽之变易，解析《滴天髓》“关内织女，关外牛郎”之奥秘。
5. **《项目周礼观》实战命理沙盘演练**：
   * 一键载入项目中记载的经典实战八字局（乙木双透、巳午极旺、丑土被烤、金弱水蒸之局）。
   * 盘面直观显现阻滞红光断点（火→土焦→金弱→水涸）。
   * 点击“辰土通关调理”，演示引入辰土（湿土泄火、生金、涵水）后，全盘气机瞬间冰融川流，恢复生生不息！
6. **动态调参实验室**：
   * 实时滑动木火土金水五气滑块，即时演算全局衡度、瓶颈堵点与通关方案。

## 肆 · 运行与使用

本平台采用纯正的前端技术栈（标准 HTML5 + SVG + 现代原生 ES6），**零外部庞杂框架依赖，开箱即用**：

1. **直接浏览**：
   直接在浏览器中双击打开项目根目录下的 `index.html`，即可体验完整的古典 Web 门面与可交互五行盘。
2. **本地静态服务器预览**（可选）：
   ```powershell
   # 使用 Python 启动本地静态服务器
   python -m http.server 8080
   # 在浏览器中访问 http://localhost:8080
   ```
